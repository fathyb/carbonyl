## [Unreleased]

### Added

- Added core TTY rendering engine based on a fathyb/carbonyl (Chromium) fork
- Added support for modern web standards (HTML5, CSS3, JavaScript, WebGL)
- Added Brave-like privacy engine using adblock-rust for ad and tracker blocking
- Added deep network request interception via Chromium's URLLoaderRequestInterceptor
- Added a hybrid rendering engine with a toggleable chafa-based ASCII art mode for images
- Added a multi-tab, command-palette TUI shell using ratatui
- Added persistent history and bookmark datastore using rusqlite
- Added a persistent cache and filter list datastore using redb
- Added full mouse (click, scroll) and keyboard input support
- Added a TUI command palette for browser functions
- Added persistent configuration for user settings
